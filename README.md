# CodeAlpha_IrisFlowerClassification
This repository contains Task 1 of my Data Science Internship at CodeAlpha. The objective is to build a Machine Learning model that can classify Iris flowers into three distinct species (Setosa, Versicolor, Virginica) based on their sepal and petal measurements

Tech Stack & Libraries: Python, Pandas, Scikit- Learn

Data Preprocessing: Loaded the Kaggle dataset, removed the unnecessary Id column, and used LabelEncoder to convert categorical species names into numerical format.

Data Splitting: Divided the dataset into an 80% training set and a 20% testing set.

Model Training: Trained a DecisionTreeClassifier to recognize patterns in the flower measurements.

Evaluation: The model achieved an accuracy of 100% on the test data, successfully classifying all unseen flowers.

Iris_Classification.ipynb: The complete Jupyter Notebook containing the Python code and workflow.

Iris.csv: The dataset used for training and testing.
